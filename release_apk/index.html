⚡ Hướng dẫn cài đặt Chrome Extension (1 phút)
  1. Bấm nút Tải Chrome Extension (ZIP) phía trên và giải nén ra thư mục.
  2. Mở trình duyệt Google Chrome, truy cập: chrome://extensions
  3. Bật công tắc Developer mode (Chế độ nhà phát triển) ở góc trên bên phải.
  4. Bấm nút Load unpacked (Tải tiện ích đã giải nén) và chọn thư mục vừa giải nén.
  5. Mở trang đọc RIS, bắt đầu đọc trên điện thoại để tự động điền!
